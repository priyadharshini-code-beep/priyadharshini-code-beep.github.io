Forecasting 90 days of retail sales using time series decomposition and moving-average models, with interactive Plotly visualisations.
Published

April 10, 2026

Overview

Accurate sales forecasting is essential for inventory management, staffing, and revenue planning. This project applies classical time series decomposition and moving-average smoothing to forecast 90 days of retail sales, with results presented in an interactive Plotly dashboard accessible to non-technical stakeholders.

Data & Approach

The dataset contains 2 years of daily retail sales. Before modelling, stationarity was checked using the Augmented Dickey-Fuller (ADF) test, and strong weekly seasonality (peaking Fridays/Saturdays) was confirmed visually.

A multiplicative decomposition was chosen over additive because seasonal amplitude grew proportionally with the trend — a common pattern in growing retail businesses.

Time Series Decomposition

The sales series was decomposed into three components using statsmodels:

from statsmodels.tsa.seasonal import seasonal_decompose

result = seasonal_decompose(
    sales_series,
    model='multiplicative',
    period=7           # weekly seasonality
)

trend    = result.trend
seasonal = result.seasonal
residual = result.resid

Decomposing first allows us to forecast the trend and seasonal components separately, then recombine them — giving more accurate and interpretable results than black-box methods.

Forecasting Method

A 28-day rolling moving average was applied to the trend component to smooth noise and project forward. The seasonal component (weekly pattern) was layered back in multiplicatively to produce the final 90-day forecast.

Confidence intervals were estimated from the standard deviation of residuals, providing ±1 and ±2 standard deviation bands.

import numpy as np
import pandas as pd

# 28-day MA on trend
trend_ma = trend.rolling(window=28, center=True).mean()

# Project trend forward (linear extrapolation of last 30 days)
trend_slope = np.polyfit(range(30), trend_ma.dropna().values[-30:], 1)
trend_forecast = np.polyval(trend_slope, range(1, 91))

# Layer back seasonal component (average seasonal pattern)
seasonal_pattern = seasonal[-7:].values  # last full weekly cycle
seasonal_forecast = np.tile(seasonal_pattern, 13)[:90]

# Final forecast = trend × seasonal
forecast = trend_forecast * seasonal_forecast

# Confidence intervals from residual std
resid_std = residual.std()
upper_1 = forecast * (1 + resid_std)
lower_1 = forecast * (1 - resid_std)

An 8.3% MAPE on the holdout period is well within acceptable range for retail planning purposes (industry benchmark: <10–15% for daily forecasts).

Conclusion

Classical time series methods remain highly effective for retail sales forecasting, especially when data history is limited or interpretability matters for business stakeholders. The interactive Plotly dashboard makes forecasts accessible to the whole organisation — not just data teams.

Key learnings:

  • Multiplicative decomposition is appropriate when seasonal swings scale with the trend
  • Residual-based confidence intervals give stakeholders a realistic range, not just a point estimate
  • Plotly dashboards dramatically improve the communicability of analytical outputs
