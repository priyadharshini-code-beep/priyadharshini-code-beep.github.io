The Question

Not every customer is equally valuable — and not every customer should get the same marketing treatment. How can we segment a customer base into meaningful groups using only three simple signals: Recency, Frequency, and Monetary value?

The Approach

RFM (Recency, Frequency, Monetary) is a classic marketing framework. I combine it with K-Means clustering to identify natural customer segments without hand-picking thresholds.

Note

Data in this project is synthetic — generated to simulate realistic retail patterns. The methodology is what matters; the same pipeline runs on real transaction data without changes.

Step 1 — Generate the data

Code 
import pandas as pd
import numpy as np
from datetime import datetime, timedelta

np.random.seed(42)

n_customers = 1000
today = datetime(2026, 4, 15)

# Simulate customer behaviour with three archetypes mixed in
customer_ids = range(1, n_customers + 1)
recency = np.concatenate([
    np.random.randint(1, 30, 300),     # active
    np.random.randint(30, 120, 500),   # moderate
    np.random.randint(120, 365, 200)   # lapsed
])
frequency = np.concatenate([
    np.random.randint(10, 50, 300),
    np.random.randint(3, 10, 500),
    np.random.randint(1, 3, 200)
])
monetary = np.concatenate([
    np.random.uniform(500, 5000, 300),
    np.random.uniform(100, 500, 500),
    np.random.uniform(10, 100, 200)
]).round(2)

rfm = pd.DataFrame({
    'CustomerID': customer_ids,
    'Recency': recency,
    'Frequency': frequency,
    'Monetary': monetary
})

Step 3 — Cluster with K-Means

Code 
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

# Scale features (K-Means is distance-based, so scale matters)
scaler = StandardScaler()
rfm_scaled = scaler.fit_transform(rfm[['Recency', 'Frequency', 'Monetary']])

# Fit K-Means with 4 clusters
kmeans = KMeans(n_clusters=4, random_state=42, n_init=10)
rfm['Cluster'] = kmeans.fit_predict(rfm_scaled)

# Profile each cluster
cluster_profile = rfm.groupby('Cluster').agg(
    Count=('CustomerID', 'count'),
    AvgRecency=('Recency', 'mean'),
    AvgFrequency=('Frequency', 'mean'),
    AvgMonetary=('Monetary', 'mean')
).round(1)

Step 4 — Name the segments

Based on the cluster profile, I can assign meaningful labels:

Code 
segment_names = {
    rfm.groupby('Cluster')['Monetary'].mean().idxmax(): '🌟 Champions',
    rfm.groupby('Cluster')['Recency'].mean().idxmax(): '💤 At Risk',
    rfm.groupby('Cluster')['Frequency'].mean().idxmin(): '🆕 New / Occasional',
}
# Fill in the remaining cluster
remaining = set(rfm['Cluster'].unique()) - set(segment_names.keys())
for c in remaining:
    segment_names[c] = '👥 Loyal Regulars'

rfm['Segment'] = rfm['Cluster'].map(segment_names)

segment_summary = rfm.groupby('Segment').agg(

What this tells the business

ImportantTakeaways
  • 🌟 Champions are a small group but contribute the lion’s share of revenue — protect them with loyalty perks and early access, not discounts.
  • 💤 At Risk customers haven’t ordered in months. A targeted win-back campaign (personalised offer, not a generic 10%) is the highest-ROI move here.
  • 🆕 New / Occasional customers need nurturing — educational content, first-purchase offers, onboarding sequences.
  • 👥 Loyal Regulars are the backbone. Cross-sell and upsell fit best here.

What I learned

  • Scaling matters. K-Means with raw RFM values put everything into the monetary dimension. Standardising gave genuinely 3D clusters.
  • K selection is a judgement call. I used 4 after inspecting the elbow plot, but 3 and 5 were both defensible. In practice you’d validate against business intuition.
  • Naming segments is the real deliverable. Cluster 2 / 3 means nothing to marketing. “At Risk” does.
