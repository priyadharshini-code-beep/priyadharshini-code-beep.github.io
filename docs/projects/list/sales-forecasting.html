Forecasting 90 days of retail sales using time series decomposition and moving-average models, with interactive Plotly visualisations.
Author

Priyadharshini Balaji

Published

April 10, 2026

The Question

What will our sales look like for the next quarter? Accurate short-horizon sales forecasts drive staffing, stock, and cash-flow decisions. I build a simple but honest forecast pipeline on two years of synthetic daily sales.

The Approach

  1. Generate a realistic-looking sales series (trend + weekly seasonality + noise)
  2. Decompose it into components so we understand what is moving
  3. Forecast the next 90 days with moving-average smoothing
  4. Build an interactive dashboard to explore the forecast

Step 1 — Simulate daily sales

Code 
import pandas as pd
import numpy as np
import plotly.graph_objects as go
import plotly.express as px
from plotly.subplots import make_subplots

np.random.seed(7)

# 730 days ending today
dates = pd.date_range(end='2026-04-15', periods=730)

# Trend: slow upward growth
trend = np.linspace(1000, 1800, 730)

# Weekly seasonality: weekends ~30% higher
day_of_week = dates.dayofweek
weekly = np.where(day_of_week >= 5, 300, 0) + np.sin(day_of_week * np.pi / 3.5) * 80

# Yearly seasonality: December spike
month = dates.month
yearly = np.where(month == 12, 400, 0) + np.where(month.isin([6, 7]), 150, 0)

# Noise
noise = np.random.normal(0, 60, 730)

sales = (trend + weekly + yearly + noise).round(2)

df = pd.DataFrame({'Date': dates, 'Sales': sales})

fig = px.line(df, x='Date', y='Sales', template='plotly_white')

Step 3 — Decompose into trend, season, residual

Code 
# Simple moving averages to extract components
df['Trend'] = df['Sales'].rolling(window=30, center=True).mean()
df['Detrended'] = df['Sales'] - df['Trend']
df['Seasonal'] = df.groupby(df['Date'].dt.dayofweek)['Detrended'].transform('mean')
df['Residual'] = df['Sales'] - df['Trend'] - df['Seasonal']

fig = make_subplots(rows=3, cols=1, shared_xaxes=True,
                     subplot_titles=('Trend (30-day moving average)', 'Weekly seasonality', 'Residual'))

fig.add_trace(go.Scatter(x=df['Date'], y=df['Trend'], line=dict(color='#6a4c93'), name='Trend'), row=1, col=1)
fig.add_trace(go.Scatter(x=df['Date'], y=df['Seasonal'], line=dict(color='#1982c4'), name='Season'), row=2, col=1)
fig.add_trace(go.Scatter(x=df['Date'], y=df['Residual'], line=dict(color='#ff595e'), name='Residual'), row=3, col=1)

fig.update_layout(height=600, showlegend=False, template='plotly_white')
fig.show()

The decomposition confirms the trend is genuinely increasing (business growing), the weekly seasonality is stable (reliable to forecast), and the residual is well-behaved (no missed pattern).

Step 4 — Forecast the next 90 days

Code 
# A simple but honest forecast: trend projection + average seasonality
future_dates = pd.date_range(start=df['Date'].max() + pd.Timedelta(days=1), periods=90)

# Extend the trend linearly from last known trend value
last_trend = df['Trend'].dropna().iloc[-15:].mean()
trend_slope = (df['Trend'].dropna().iloc[-15:].mean() - df['Trend'].dropna().iloc[-45:-30].mean()) / 30
future_trend = last_trend + trend_slope * np.arange(1, 91)

# Apply the weekly seasonality map
dow_seasonality = df.groupby(df['Date'].dt.dayofweek)['Seasonal'].mean()
future_seasonal = future_dates.to_series().dt.dayofweek.map(dow_seasonality).values

forecast = future_trend + future_seasonal

# 80% confidence interval from residual std
residual_std = df['Residual'].std()
upper = forecast + 1.28 * residual_std
lower = forecast - 1.28 * residual_std

forecast_df = pd.DataFrame({
    'Date': future_dates,
    'Forecast': forecast.round(2),
    'Upper': upper.round(2),
    'Lower': lower.round(2)
})

fig = go.Figure()
fig.add_trace(go.Scatter(x=df['Date'], y=df['Sales'], name='Historical',
                          line=dict(color='#6a4c93', width=1)))
fig.add_trace(go.Scatter(x=forecast_df['Date'], y=forecast_df['Forecast'], name='Forecast',
                          line=dict(color='#ff595e', width=2)))
fig.add_trace(go.Scatter(x=forecast_df['Date'], y=forecast_df['Upper'], name='Upper 80%',
                          line=dict(color='#ff595e', dash='dot', width=0.5), showlegend=False))
fig.add_trace(go.Scatter(x=forecast_df['Date'], y=forecast_df['Lower'], name='80% CI',
                          line=dict(color='#ff595e', dash='dot', width=0.5),
                          fill='tonexty', fillcolor='rgba(255, 89, 94, 0.15)'))

fig.update_layout(height=450, template='plotly_white',
                  title='90-Day Sales Forecast with 80% Confidence Band',
                  yaxis_title='Sales (€)', xaxis_title='')
fig.show()

Code 
total_forecast = forecast_df['Forecast'].sum()
avg_daily = forecast_df['Forecast'].mean()
peak_day = forecast_df.loc[forecast_df['Forecast'].idxmax(), 'Date']

summary = pd.DataFrame({

    'Value': [f'€{total_forecast:,.0f}',

What this tells the business

ImportantActionable insights
  • Staff up for weekends — the Saturday/Sunday lift is consistent enough to plan for.
  • The forecast trend is upward, reflecting the underlying growth — capacity planning should reflect that, not flat last-year numbers.
  • The 80% confidence band is tight enough to give stock planners a usable range. Revisit in 30 days with actuals.

What I learned

  • Decomposition before forecasting is non-negotiable. Looking at trend/season/residual separately showed the pattern was stable and the model could be simple.
  • A simple model that you understand beats a complex one you don’t. I could have reached for Prophet or ARIMA, but a moving-average + seasonal map is transparent, cheap to retrain, and adequately accurate for a 90-day horizon.
  • Confidence bands matter more than point estimates — decision-makers need to know the uncertainty, not a pretend-precise single line.

Next steps

## What I learned

- **Decomposition before forecasting** is non-negotiable. Looking at trend/season/residual separately showed the pattern was stable and the model could be simple.
- **A simple model that you understand** beats a complex one you don't. I could have reached for Prophet or ARIMA, but a moving-average + seasonal map is transparent, cheap to retrain, and adequately accurate for a 90-day horizon.
- **Confidence bands matter more than point estimates** — decision-makers need to know the uncertainty, not a pretend-precise single line.
